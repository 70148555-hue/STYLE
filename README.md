## 🔥 Features

### Authentication
- Email/Password Login
- Google Login
- Reset Password
- Delete Account

### Role System
- Admin Dashboard
- User Dashboard
- Protected Routes

### CRUD System
- Add Products
- Edit Products
- Delete Products
- User-based ownership

### Chat System
- Real-time messaging
- Buyer ↔ Seller chat
- Firestore-based sync

- Firebase Authentication
